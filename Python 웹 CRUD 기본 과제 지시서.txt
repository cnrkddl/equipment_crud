5. 필수 구현 기능
5-1. 장비 등록: Create

사용자가 입력한 장비 정보를 데이터베이스에 저장한다.

필수 조건:

장비번호와 장비명은 필수 입력
장비번호는 중복 등록 불가
등록 성공 후 장비 목록 화면으로 이동
등록 완료 메시지 출력

예시 URL:
GET  /equipment/create
POST /equipment/create

5-2. 장비 목록 조회: Read
등록된 장비 전체를 표 형태로 출력한다.

목록에 표시할 내용:
장비번호
장비명
설치장소
장비상태
등록일
상세보기 버튼
수정 버튼
삭제 버튼

예시 URL:
GET /equipment

5-3. 장비 상세 조회: Read
선택한 장비의 전체 정보를 조회한다.

예시 URL:
GET /equipment/<id>

표시 내용:
장비의 모든 등록 정보
목록으로 돌아가기 버튼
수정 버튼
삭제 버튼

5-4. 장비 정보 수정: Update
기존에 등록된 장비 정보를 수정한다.

필수 조건:
수정 화면에는 기존 값이 표시되어야 함
필수 입력값을 검사해야 함
수정 성공 후 상세 또는 목록 화면으로 이동
존재하지 않는 장비 접근 시 오류 처리

예시 URL:
GET  /equipment/<id>/edit
POST /equipment/<id>/edit

5-5. 장비 삭제: Delete
선택한 장비 정보를 데이터베이스에서 삭제한다.

필수 조건:
삭제 전 확인 메시지 표시
삭제 요청은 POST 방식으로 처리
삭제 완료 후 목록 화면으로 이동
존재하지 않는 장비 삭제 요청에 대한 오류 처리

예시 URL:
POST /equipment/<id>/delete

6. 데이터베이스 구조

테이블명:
equipment

예시 모델:
class Equipment(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    equipment_code = db.Column(db.String(30), unique=True, nullable=False)
    name = db.Column(db.String(100), nullable=False)
    location = db.Column(db.String(100))
    status = db.Column(db.String(20), default="정상")
    registered_at = db.Column(db.DateTime, default=datetime.utcnow)
    description = db.Column(db.Text)

9. 입력값 검증

다음 사항은 반드시 검사한다.

장비번호가 비어 있는지 확인
장비명이 비어 있는지 확인
장비번호 중복 여부 확인
입력 문자열 앞뒤 공백 제거
존재하지 않는 ID 접근 처리
데이터베이스 저장 실패 시 예외 처리

잘못된 입력이 발생하면 프로그램이 종료되지 않고 사용자에게 메시지를 보여줘야 한다.

예시:
장비번호를 입력해 주세요.
이미 등록된 장비번호입니다.
해당 장비를 찾을 수 없습니다.
